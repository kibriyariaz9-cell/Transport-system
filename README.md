# Transport Management System

A console-based **Transport Management System** developed in **C++** using Object-Oriented Programming (OOP). The system helps manage transport operations by allowing users to register, manage vehicles, routes, and transport records.

## Features

- User login and registration
- Add and manage vehicles
- Manage transport routes
- Generate transport records
- File handling for data storage
- Menu-driven interface

## Technologies Used

- C++
- Object-Oriented Programming (OOP)
- File Handling
- Standard Template Library (STL)

## How to Run

Compile the project:

```bash
g++ *.cpp -o transport_system
```

Run the program:

**Windows**
```bash
transport_system.exe
```

**Linux/macOS**
```bash
./transport_system
```
